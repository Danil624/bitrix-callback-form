# Bitrix Callback Form

Тестовое задание: форма «Обратный звонок» для 1С-Битрикс.

## Стек

- 1С-Битрикс
- Модуль «Веб-формы»
- `bitrix:form.result.new`
- Vue 3
- sprint.migration

## Функциональность

- модальное окно автоматически открывается через 20 секунд;
- поля формы настраиваются в административной части Bitrix;
- поля не захардкожены во Vue;
- PHP формирует JSON-конфигурацию на основе веб-формы;
- Vue динамически отрисовывает полученные поля;
- обязательные поля:
  - Имя;
  - Телефон;
  - Согласие на обработку персональных данных;
- необязательное поле:
  - Комментарий;
- клиентская валидация;
- проверка номера телефона;
- отправка через `bitrix:form.result.new`;
- результат сохраняется в веб-форме Bitrix;
- адаптивное модальное окно;
- форма создаётся/обновляется миграцией sprint.migration.
